# CopChat

Secure internal communication app for Rajasthan Police.

Built with Flutter using a feature-first MVVM architecture and Riverpod for state
management. Backend is Supabase.

## Features

- Secure login with role-based access (Super Admin, PHQ Admin, Department Head, Officer)
- One-to-one and department group chat, end-to-end encrypted
- Voice and video calling
- Live officer location tracking
- Emergency SOS and priority broadcasts
- Image and document sharing

## Setup

```bash
flutter pub get
flutter run
```
